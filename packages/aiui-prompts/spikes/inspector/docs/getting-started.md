# Running the unpublished inspector spike

This package is only available in the repository. From its root, run:

```sh
pnpm --filter @habemus-papadum/aiui-prompts-inspector-spike dev
```

Open <http://127.0.0.1:5217>. Follow the [interaction checklist and limitations](../README.md).
The displayed prompt/source artifacts are hand-authored fixtures; they are not compiler output.
